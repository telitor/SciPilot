三、最小复现
1. 安装 Python 3.11、Node.js 20+ 与 npm；如需生产部署，另装 Docker Engine 24+ / Compose v2.20+。
2. 复制 backend/.env.example 为 backend/.env，仅在本地或部署平台填入真实配置，严禁提交。
3. 后端：安装 backend/requirements.lock 或 requirements.txt 后运行 FastAPI。
4. 前端：在 frontend 安装 package-lock.json 锁定依赖后运行 npm run dev。
5. 生产：参见 deploy/README.md，先运行 deploy/manage.py preflight，再使用不可变 Git 标签发布和验证。
